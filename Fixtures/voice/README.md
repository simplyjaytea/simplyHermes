# Voice fixtures

`utterance-synthetic-16k.wav` is synthetic, not a recording of a person: 16 kHz mono 16-bit PCM with 0.5 s of quiet,
1.2 s of loud noise, a 0.3 s dip, 0.6 s more loud noise and 1.2 s of quiet. It is generated by a fixed-seed script,
so it reproduces byte for byte: `python3 tools/voice/make_utterance_fixture.py`. Use it to test the speech detector and the WAV layout. Real speech checks run on device.
