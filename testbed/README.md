# Testbed (WP-03)

Disposable Hermes backend for CI and local runs. Docker only.

| Service | Port | What |
|---|---|---|
| `dashboard` | 9119 | `hermes serve` bound to `0.0.0.0`, so the auth gate is on: basic provider, user `tester`, password `testbed-password`, stable `HERMES_DASHBOARD_BASIC_AUTH_SECRET`. |
| `sshd` | 2222 | OpenSSH, user `tester`, key `testbed/data/ssh/id_ed25519` (generated by `scripts/up.sh`), Hermes on `PATH`. The client starts `hermes serve` over SSH. |
| `fake-llm` | 8700 | Scripted OpenAI-compatible LLM. Both Hermes homes point at it. |
| `dex` | 5556 | Optional local OIDC (`--profile oidc`, host network). User `tester@example.com`, password `password`. |
| `dashboard-oidc` | 9120 | Optional (`--profile oidc`, host network): `hermes serve` gated by Dex through the `self-hosted` provider. Used by the WP-13 OIDC sign-in test. |

Hermes is built from upstream git at the commit in `hermes/Dockerfile` (`HERMES_REF`). PyPI `hermes-agent` 0.19.0 is too old (no `client.capabilities`, `session.events.since`, `groups.*`). Bump `HERMES_REF` deliberately and re-record fixtures.

```sh
testbed/scripts/up.sh              # build + start, waits for healthy
python3 -m venv .venv && .venv/bin/pip install websockets
.venv/bin/python testbed/smoke_test.py
testbed/scripts/scenario.sh tool_call
testbed/scripts/down.sh
```

## Fake LLM scenarios

`fake-llm/scenarios/*.json`. Pick one per message with `[[scenario:NAME]]` in the prompt, or sticky with `scripts/scenario.sh NAME`. Default is `text`. Format is documented at the top of `fake-llm/server.py`.

| Name | Behaviour |
|---|---|
| `text` | One short reply. |
| `tool_call` | `terminal` tool call (`echo`), then a final reply. |
| `approval` | Dangerous `terminal` command that triggers an approval request. |
| `clarify` | `clarify` tool call with two questions (one with choices). |
| `sudo` | `terminal` `sudo -n true`. |
| `error_429` | HTTP 429 with `Retry-After: 30`. |
| `error_500` | HTTP 500. |
| `delegate` | `delegate_task` tool call (background subagent). |
| `medium_stream` | 120 chunks at 60 ms; for drop/catch-up tests. |
| `long_stream` | ~48 KB streamed in small chunks. |
| `slow` | Slow stream, for interrupt tests. |

`GET /__log` on the fake LLM shows recent requests.

Real provider key (manual runs): `docker compose exec dashboard hermes config set ...` or edit `/data/hermes/config.yaml` in the container.
